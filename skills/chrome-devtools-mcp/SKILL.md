# Chrome DevTools MCP

Use `kodex chrome-devtools` CLI instead of MCP tool calls directly.

Capabilities: pages & navigation, a11y snapshots & screenshots, input/form interaction, JS/CSS inspection, console/network/logpoints, emulation, Lighthouse, performance traces, heap snapshots, screencasts.
