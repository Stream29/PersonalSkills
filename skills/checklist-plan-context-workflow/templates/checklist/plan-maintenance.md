# Plan Maintenance

## Purpose

- Use `plan/` only for ordered task orchestration.
- Do not store concrete design details in `plan/`. Store them in checklists.
- Use a plan file for complex long-running work.

## File Format

- Name each plan file as `YYYY-MM-DD-title.md`.
- Keep each plan file to a simple unordered list of tasks.
- Record what needs to be done, in what order, and how tasks are sequenced.
- Do not use checkbox markers.
