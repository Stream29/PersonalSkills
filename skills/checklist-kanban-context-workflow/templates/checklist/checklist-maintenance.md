# Checklist Maintenance

This file is the checklist for maintaining the `checklist/` directory itself.

- Keep this maintenance checklist inside `checklist/`.
- Prefer small focused checklist files over one large document.
- Keep every item actionable, concrete, and easy to mark done.
- Use plain Markdown unordered lists, not checkbox markers.
- Do not use numeric prefixes in checklist filenames.
- Do not store research findings in this directory.
- Do not store task decomposition in this directory.
- Do not store open questions in this directory.
- When uncertain, ask the user directly instead of writing the uncertainty to disk.
- When the user resolves a question, record the decision in the relevant checklist file.
- Avoid duplicating the same checklist item in multiple files.
- If duplication is useful, make one item canonical and link to it from others.
- Use relative links between checklist files.
- Avoid temporary files when editing this directory.
- Remove any temporary extraction or generated files after use.
