# Feishu Browser

## Entry Points

- Web Messenger and search:
- Documents
- Knowledge AI
- Minutes

## Pitfalls

- Wrong company, valid login: the user may have multiple employers' Feishu accounts which have different permissions.
- Feishu docs from markdown: It's not easy to edit Feishu docs in the browser. It's easier to edit a local markdown file and upload it to Feishu. But do it with caution: mermaid diagrams should be reconstructed in native Feishu diagrams. And some formatting may corrupt. eg. code blocks.
